CueMol 3.0.0 (build 554)

From this release the version number follows the app's name: CueMol3 is now
version 3. The repository has moved to
[github.com/CueMol/cuemol3](https://github.com/CueMol/cuemol3); links to the
old `CueMol/cuemol2` address are redirected.

The main changes:

- **ChimeraX console (CueMol3)**: a third console dialect, `ChX>`, for
  ChimeraX commands and atom specifications.
- **Console dialects as plugins (CueMol3)**: the PyMOL and ChimeraX dialects
  can each be switched on or off in **Settings > Plugins**.
- **tritium_cli (CueMol3)**: opens files in the running app, installs an agent
  skill, and bridges MCP over stdio.
- **Undo (CueMol2 and CueMol3)**: deleting part of a residue can now be
  undone, and a failed undo is reported instead of leaving the scene half
  changed without a word.
- **Shorter selections (CueMol2 and CueMol3)**: selections built step by step
  no longer grow longer with every step.

---

## Undo fixes (CueMol2 and CueMol3)

- **Undoing the deletion of part of a residue did not bring the atoms back**
  (for example, deleting only the CA atoms of the glycines). Deleting whole
  residues worked. Deleted atoms now come back under their own atom IDs, so
  later coordinate undo and `aid` selections still reach them. Alternate
  conformations removed along with an atom come back too.
- **A failed undo, redo or rollback** used to leave the History saying a step
  was undone while the scene was only partly changed, and later edits could
  silently stop being recorded. Now the undo history is cleared when a step
  fails, and CueMol3 tells you which step failed and how many were undone
  first (an error alert in the GUI, a message in the console).

## Shorter selections (CueMol2 and CueMol3)

- Selections built by adding to the current one (shift-click / Add select,
  rubber-band and lasso add, the Selection Builder, the console dialects) are
  rewritten into an equivalent, shorter expression instead of growing like
  `((((aid 5) or (aid 9)) or ...`. An expression you type is kept as typed.
- The 3D view's context menu **Invert**, **Toggle sidechain** and **Around**
  now work on the parsed selection. Before, they edited the text and could
  break some expressions (inverting `!(A) or !(B)` gave `A) or !(B`).
- A selection written back as text now compiles to the same atoms
  (`none`, `null`, named selections and quoted values included).

## ChimeraX console (CueMol3)

Switch the console to **ChX** (or run `tritium_cli --dialect chimerax`).
Commands are translated into CueMol's ops, so they are checked, recorded in
the History and undone like any other edit.

- **Opening and display**: `open` (files, PDB IDs, `.cxc` scripts, with
  ChimeraX's automatic styling), `close`, `delete`, `show` / `hide`,
  `cartoon`, `style`, `surface`, `transparency`, `label`.
- **Colour**: `color` with names, `#hex`, `rgb()` / `hsl()` / `gray()` and the
  other ChimeraX forms, `byhetero`, `byelement`, `bychain`, `bymodel`,
  `random`, and `rainbow` with palettes.
- **Atom specifications**: models, chains, residues and atoms, wildcards,
  zones (`@<5`), attribute tests (`@@bfactor>50`, `::polymer_type`), named
  selections and `sel`.
- **View**: `view`, named views, `view matrix`, `turn`, `move`, `zoom`,
  `cofr`, `set bgColor`, silhouettes.
- **Selection and analysis**: `select` (with `add` / `subtract` /
  `intersect`), `name`, `info`, `alias`, `distance`, `align`, `matchmaker`,
  `save` (`.png`, `.qsc`, `.pdb`).

See `docs/architecture/console-chimerax-dialect.md` for what differs from
ChimeraX.

## PyMOL console (CueMol3)

- Every command that changes the scene now runs through the same ops as the
  native console, MCP and the AI agent, so it is checked and recorded in the
  History the same way. Error messages are unchanged.
- The PyMOL and ChimeraX dialects are now plugins of their own
  (`pymol-console`, `chimerax-console`). Both are on by default; existing
  console history carries over.

## tritium_cli (CueMol3)

- `tritium_cli 1crn.pdb map.ccp4` opens the files in the running app (`-i`
  continues at the prompt). `.qax`, `.pml` and `.txt` files run as scripts.
- `tritium_cli skill install` installs an agent skill for Claude Code that
  drives CueMol through `tritium_cli`.
- `tritium_cli mcp` connects an MCP client over stdio, even when the MCP
  Server plugin is off.
- `status`, `version` and `help <command>` subcommands.
- Only one client edits at a time: a second console or MCP client is told the
  app is busy rather than interleaving its commands.
- Published to npm as `@cuemol/tritium-cli@3.0.0`.

## Console ops (CueMol3)

- `focus_nodes`: fit the view to several objects and renderers at once (the
  scene tree's Focus with several rows selected).
- `focus_selection` replaces `center_view` and no longer changes the
  object's selection.
- `fetch_pdb` takes the reader options of the File Open dialog
  (`build2ndry`, `loadAltConf`, ...), and Get PDB records them.
- `save_scene` takes the Save As options (`embedAll`, `version`, `compress`,
  `base64`); `superpose` takes `recenter`.
- New `copy_node`, `orient_view`, `set_frame`; `set_view` takes a rotation.
- A `load_file` recorded from File Open keeps the reader you chose, so a
  replay does not pick another one by extension.
