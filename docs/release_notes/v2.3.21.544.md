CueMol 2.3.21 (build 544)

This release is about **driving CueMol3 from outside the window**. Every
operation is now declared once and offered from the same definition to the AI
agent, to a new **native console**, to an **MCP server** that Claude Code, Codex
and other MCP clients can connect to, and to **`tritium_cli`**, a command line
client shipped with the app. Together they cover most of what the GUI edits:
scenes, views and cameras, renderers and styles, coloring and paint, maps,
superposition and other molecule operations, rendering, electrostatics, surface
cutting and morphing.

Labels can now be drawn **on top of the geometry** and **aligned** on their
atom, with a new name-label inspector page. The Color pane's **Paint list** is
restyled and can be reordered by drag and drop, and an Undo bug that left
duplicate paint rows behind is fixed. On Windows, windows no longer appear one
to two seconds late.

CueMol2 (the UXP app) picks up the shared core fixes: the paint Undo fix and the
new label properties.

## Console (CueMol3, on by default)

The PyM Console is now the **Console** plugin, with two dialects you switch
between in the panel:

- **native** (the default): commands for CueMol's own operations, CueMol
  selections, objects named as `obj` / `obj.rend` / `#uid`, properties set with
  `set obj.rend.prop, value`, and Tab completion that knows each argument --
  values of the parameter, `name=` for the ones not given yet, renderer
  properties, file paths. `help` lists commands by subject; `help <subject>`
  lists one subject.
- **pymol**: the PyMOL-compatible commands of the previous release, unchanged.

One submission is one undo step, as before; Stop, scripts and the log work in
both dialects.

Commands of the native dialect include:

- **Scenes**: `list_scenes`, `new_scene`, `switch_scene`, `close_scene`.
- **View and cameras**: rotate, zoom, slab, center, pan, focus, projection,
  named cameras (save, apply, rename, move), and View properties through
  `view.` paths (`get view.stereoMode`, `set view.centerMark, axis`).
- **Objects and renderers**: delete, rename, change renderer type, renderer
  styles, named selections, reset properties to their defaults.
- **Molecules**: superpose, molecular surfaces, delete atoms, rename chains,
  change residue numbers, merge, secondary structure, add / remove bonds,
  symmetry, groups.
- **Coloring**: paint entries (list, add, update, remove, move), clear paint,
  default color, color by electrostatic potential.
- **Maps**: fetch maps, contours, recenter.
- **Tools-menu operations**: `calc_elepot` (the same APBS job as the dialog,
  using the paths in Settings), the molecular surface cutter, and the morphing
  animation tool. Interactions can be listed and removed.
- **Files and images**: `load` picks the reader the way File > Open does;
  `load_pdb`, `load_mtz`, `load_ccp4`, `load_msms`, `load_namd`, `load_amber`
  take the File Open dialog's options as named arguments (e.g.
  `load_pdb f.pdb, build2ndry=false`). Scene export to PNG / POV-Ray / STL /
  MQO, `export_image`, and `ray`, which runs the umbreon render (GI or NPR)
  and can be stopped.
- **Animation**: playback including pause and seek.

Command names follow one `verb_object` pattern (`list_anims`, `add_paint`,
`create_surface`, ...).

## MCP server (CueMol3, off by default)

Turn it on from the status bar item or **Settings > Plugins > MCP Server**.

- CueMol3 listens on `127.0.0.1` (port 27182 by default) with a bearer token,
  and refuses requests from web pages.
- The status bar shows whether the server is off, ready, running a tool (with
  its name) or in error. Its popover has a setup dialog for **Claude Code**,
  **Codex**, **Antigravity** and other clients, and regenerates the token.
- Every console operation is offered as an MCP tool, plus `capture_view`, which
  returns an image of the current view. One tool call is one undo step
  (`MCP: <tool>`). A call is refused while the agent or the console is in the
  middle of an edit, and a cancelled call is stopped.
- Scenes can be listed, created, switched and closed; `close_scene` refuses a
  scene with unsaved changes unless told to discard them. `save_scene` and
  opening a `.qsc` work from MCP.
- Errors always come back as a readable `{ok: false, error}` result.

## `tritium_cli` (CueMol3)

A command line client for the console, shipped with the app.

- Interactive (`CueMol <dir> ❯` / `PyM>`, Tab completion, history, Ctrl-C stops
  a run), or non-interactive with `-c`, a script file or a pipe (exit status 1
  on failure).
- If CueMol3 is not running, it starts it and waits for it (`--no-launch`
  opts out). Otherwise turn on **Settings > Plugins > Console > Command line
  access**.
- Relative paths resolve against the directory you run it in. What you run
  also appears in the console panel, marked `[cli]`.
- The deb installs `/usr/bin/tritium_cli`. On macOS and Windows, Settings >
  Plugins > Console shows the path of the wrapper to add to `PATH`.

## AI agent (CueMol3, off by default)

- The agent's tools are generated from the same operation definitions. A short
  core set is always offered; further groups (view, map, molecule operations,
  analysis, ...) are switched on by the model when it needs them.
- New core tools: `rotate_view` and `set_view` (zoom, slab, distance, center).
- `create_renderer` without a name names the renderer after its type.
- Interaction analysis leaves out carbon contacts unless asked to include them.

## Labels

- **Label on top** (name labels and interaction labels; off by default): labels
  are no longer hidden by geometry in front of them, like PyMOL's
  `float_labels`.
- **Alignment** (name labels): `halign` / `valign` choose which point of the
  label sits on the atom (plus the offset). The default is the previous
  placement. POV-Ray output follows the alignment.
- CueMol3 has a **name label inspector page**: format, color, label on top, max
  labels, alignment, offset and font. The interaction labels section gains
  "Label on top".
- Any name label property change now redraws the labels; before, only the color
  did.
- Edge lines are no longer offered for renderers that have no faces (spline,
  map mesh, selection, unit cell, name labels, ...).

## Color pane (CueMol3)

- The **Paint** list is restyled to match the Camera pane, with an Add / Move
  up / Move down / Delete toolbar, Delete / Backspace to delete rows, and
  **drag and drop to reorder**.
- The coloring dropdown shows the current mode (Paint, CPK, Rainbow, ...).
- **Undo after adding a paint row, or after moving one to the end, no longer
  leaves a duplicate row.** This was a core bug and is fixed in CueMol2 too.

## Other fixes in CueMol3

- **Windows: windows appear without delay.** The Rendering window appeared
  about a second, and the main window about two seconds, after they were ready.
  Both now show within about 0.15 s.
- **PNGs saved from the Rendering window keep their DPI.** Images rendered with
  umbreon (GI or NPR) were saved without resolution information; they now carry
  the render settings' DPI, as File > Export PNG does.
- **The hover highlight survives a click.** Clicking an atom (for example to add
  a pick label) no longer clears the highlight; it ends when the view starts
  rotating or moving.

## Known incompatibilities and limitations

- **The console plugin changed its id** (`pymconsole` -> `console`). If you had
  turned it off, turn it off again in Settings > Plugins. PyMOL command history
  is kept.
- `tritium_cli` is not available on PATH for the AppImage.
- Label alignment is not applied in the LW viewer output (labels stay at the
  bottom-left).
