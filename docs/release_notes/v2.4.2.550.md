CueMol 2.4.2 (build 550)

The main changes, all in CueMol3:

- **New default look**: each molecule loaded into a scene gets its own color
  from a colorblind-safe palette, and the default ribbon and nucleic-acid
  shapes are slimmer.
- **Cryo-EM maps**: the Get PDB dialog and the console fetch EMDB maps.
- **Finding structures**: the Get PDB dialog finds entries by keywords.
- **PyMOL-like drawing**: a molecule loaded from the console without choosing
  a renderer is drawn as cartoon, sticks, spheres and water.
- **Self-update on Windows**.

It also fixes an important bug: CueMol3 could not open some valid CCP4 / MRC
map files at all (see below).

---

## Important fix: CCP4 / MRC maps that could not be opened (CueMol3)

- **Some valid CCP4 / MRC map files (`.map`) could not be opened in CueMol3.**
  Opening one with **File > Open** (or the console's `load_file` /
  `load_ccp4`) failed: the file was taken for NAMD coordinates (`namdcoor`)
  and the NAMD reader failed on it. EMD-60887, a cryo-EM map from EMDB, is
  one such file.
- Cause: the `.map` extension is claimed by both the CCP4 and X-PLOR
  readers, so CueMol3 detects the format from the file's content. The
  check of the NAMD coordinate reader accepted a CCP4 header by mistake and
  won over the CCP4 reader.
- The NAMD check no longer accepts such a header, so these files now open as
  density maps. If a `.map` file failed to open in an earlier version, try
  it again with this release.
- Each console `load_<format>` op (`load_ccp4`, `load_pdb`, ...) now reads
  with its own reader only, without format detection; new `load_mmcif` for
  mmCIF models.

## New default look (CueMol3)

- Each molecule loaded into a scene gets its own color from a colorblind-safe
  palette (Okabe-Ito by default), instead of the same fixed colors for every
  molecule. Other palettes (`tolbright`, `tolvibrant`, `tolmuted`, `tollight`,
  `brewerset2`, `brewerdark2`, `tableau10`) can be chosen in a style file with
  `<palette id="default_paint" value="tolbright"/>`; there is no GUI for this
  yet.
- The palette color is saved in the scene, so a saved scene keeps its colors
  even if the defaults change later.
- The default ribbon is slimmer (helix and sheet width 0.18, coil width 0.2).
- The default nucleic-acid renderer has smaller bases and a round-square
  backbone tube.
- CueMol2 keeps its previous default shapes. A scene saved by CueMol3 opens
  in CueMol2 with CueMol2's shapes, and the other way round.

## Cryo-EM maps from EMDB (CueMol3)

- **Get PDB** accepts an EMDB ID (`EMD-11638` / `emd_11638`) as well as a PDB
  ID. For a cryo-EM entry it offers the entry's EMDB maps (size, grid,
  recommended level; wwPDB or EBI mirror) instead of 2Fo-Fc / Fo-Fc.
- The entry's title, method, resolution and EMDB IDs are shown as you type.
- An EMDB map is drawn as an isosurface at the author's recommended contour
  level (top 1% when there is none).
- New console op **`fetch_emdb`** (also for the AI agent and MCP): takes an
  EMDB code or the PDB ID of a cryo-EM entry. PyMOL `fetch EMD-3489` and
  `fetch 3489, type=emd` work too. Map downloads are recorded in the action
  log.

## Find an entry by keywords (CueMol3)

- The Get PDB ID field also takes keywords, searched with the RCSB full-text
  search (Enter or Search).
- Results can be filtered by method (X-ray / electron microscopy) and sorted
  by relevance, best resolution or date. **More** loads further hits.
- Picking a row fills the form as if its ID had been typed. Searched keywords
  go into the input history.

## PyMOL-like drawing on load (CueMol3)

- A molecule loaded without choosing a renderer (console `load_file` /
  `fetch_pdb` etc., the PyMOL console, MCP, the agent) is now drawn with the
  new preset **DefaultPymRendPreset**:
  - protein as ribbon, nucleic acid as nucl
  - organic ligands as sticks, inorganic ones as spheres
  - water as crosses
- In the PyMOL console, `show` / `hide` / `as` / `color` act on these parts;
  PyMOL `cartoon` maps to ribbon, PyMOL `ribbon` to a CA trace.
- File > Open with its dialog is unchanged.

## Density maps (CueMol3 and CueMol2)

- A masked cryo-EM map no longer opens with a negative default contour level.
  The Density map pane's Level field covers the levels that actually draw
  something.

## Windows self-update (CueMol3)

- CueMol3 on Windows finds, downloads and installs new releases itself, like
  the macOS build (**Check for Updates**). Each update asks for administrator
  permission (UAC prompt names `CueMol3 Updater.exe`). If the new version does
  not start, the previous one is restored.

## Other changes (CueMol3)

- Width rows of tube / ribbon / cartoon in the Inspector now go from 0 to
  1.5 A in 0.01 steps, so dragging moves about one step per pixel.
- **About** lists the commit, build date and Electron / Chromium / Node.js /
  V8 / OS versions, with a **Copy** button for bug reports.
- Electron updated to 42.11.16.
- Dragging a numeric field past its end no longer sticks there.
- Console help tables no longer break words in a narrow pane.
- A framed list with more rows than fit now scrolls instead of squeezing
  every row.

## Known limitations

- Some EMDB maps have a recommended level that is too high (e.g. EMD-11640);
  adjust the level by hand.
- The PDB reader skips unknown lines, so `load_pdb` on an mmCIF file does not
  fail.
- The default-paint palette can only be changed in a style file.
- The PyMOL-like preset does not cover every PyMOL rule (e.g. very small or
  very large objects, per-object carbon color).
